This page lists all articles in this repository with corresponding links for human readable versions. 

**For AI Agents and Automated Tools:** If you want to point a chatbot or AI assistant at this corpus, use the article index URL. The structured article index lists every article with its title, authors, miniabstract, DOI, article type, symposium, and URLs for the full-text Markdown, abstracts, figures, and data files. It is approximately 28 KB and fits within a single response. Note: the `paper.html` links in the table below are rendered from Markdown source files and are only available through the GitHub Pages site — they are not directly accessible as files in the GitHub repository. AI agents should use the raw Markdown URLs from the article index instead.

**GitHub Pages URL** (use if reachable):
```
https://liegroup-dartmouth.github.io/working-aea-jep/papers/article-index.json
```

**GitHub raw URL** (recommended, reachable from most agent network environments though larger in size):
```
https://raw.githubusercontent.com/liegroup-dartmouth/working-aea-jep/refs/heads/gh-pages/papers/article-index.json
```
