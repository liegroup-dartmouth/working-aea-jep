This site contains LLM-friendly companion files for articles published in the *Journal of Economic Perspectives*. Each article has an `.xhtml` file that is both human and machine readable.

To guide an AI model, point it directly to the article manifest:
https://liegroup-dartmouth.github.io/working-aea-jep/papers/manifest.json

Or via the GitHub blob URL (recommended if *.github.io is blocked):
https://github.com/liegroup-dartmouth/working-aea-jep/blob/gh-pages/papers/manifest.json

Navigate to the [AI Access]({{ site.baseurl }}/ai-access.html) tab for more instructions. 
 
To view articles, navigate to the [View Articles]({{ site.baseurl }}/view-articles.html) tab and find the corresponding volume, number, and year. This page also provides paper abstracts, and relevant metadata for an AI agent or researchers.

To download articles, navigate to the [Download Articles]({{ site.baseurl }}/download-articles.html) tab, and follow the instructions for ensuring you are obtaining all images and utilities needed to view the article locally.
